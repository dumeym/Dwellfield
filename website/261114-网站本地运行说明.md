# Backyard Home — local homepage preview

English-language Queensland granny-flat homepage draft based on the open-source Norven Astro codebase. The masthead “backyard” is a working identity, not an approved brand name.

## Run locally

For a quick review on this computer, double-click `261114-本地预览.cmd` and open the URL shown in its window. Keep that window open while viewing the site. The launcher serves the existing `dist/` build; it does not rebuild the site.

To build or refresh the preview after editing source files, run:

```powershell
pnpm install --ignore-scripts
$env:ASTRO_TELEMETRY_DISABLED = '1'
.\node_modules\.bin\astro.cmd build
python -m http.server 4321 --bind 127.0.0.1 --directory dist
```

Open http://127.0.0.1:4321/ in a local browser. The Astro development server currently fails on this Windows host with `require is not defined`; the static build and preview work. Stop the local server with Ctrl+C when finished.
