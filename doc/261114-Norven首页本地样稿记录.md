## 已做成的本地样稿

- 工作目录：`website/`；开发基础为 [Norven 开源仓库](https://github.com/farulivan/norven)，沿用其 Astro、字体、留白、米色/深墨色与克制动效。Norven 代码是 MIT 许可；已保留 `website/LICENSE.md`。原品牌名称、页面、商标图标、项目内容和访客可见照片未进入新页面。
- 当前页面工作品牌为 **Dwellfield**，已按用户选择用于导航、页脚和页面标题；仍待合伙人讨论与商标核查，可后续更换。
- 网站访客内容全部用澳洲英文。单页顺序：产品与后院场景 → 起居生活 → 家庭/成年子女/出租三种用途 → 室内整体/细节 → 示意平面 → 固定外观与付费选配 → 蓝调外观图 → 指示价与范围 → 地块评估到安装 → Queensland 常见问题 → 咨询表单预览。
- 价格写成 **indicative target around $150,000**，并列出预计包含与因场地而异的价格因素。没有承诺一周完工、免审批、必然可出租、固定回本周期。
- 仅本地预览：`robots.txt` 和网页 meta 均设 `noindex`；咨询入口明确标作预览，尚不收集用户信息。正式上线前需接入真实收件团队与表单流程。
